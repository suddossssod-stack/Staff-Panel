STAFF PANEL - GITHUB UPLOAD GUIDE

This is a complete, standalone Fabric mod project for Minecraft 1.21.11 / Java 21. It does NOT require ChatWatch.

1. Extract Staff-Panel-Standalone-Project.zip on your computer.
2. Open the extracted folder named staffpanel_project.
3. Select EVERYTHING INSIDE that folder (build.gradle, gradle.properties, settings.gradle, README.md, .github, and src).
4. On the GitHub Staff-Panel repository Upload files page, drag those selected items into the upload area.
   IMPORTANT: Upload the contents of staffpanel_project, not the outer folder itself. Keep the .github and src folder structure.
5. Wait for the files to finish uploading.
6. In the commit box, enter: Add standalone Staff Panel mod
7. Click Commit changes.
8. Open the Actions tab in the repository. Select the latest Build Staff Panel run.
9. Wait for it to finish. Green means the build succeeded; red means it failed.
10. If green, open the run, scroll to Artifacts, and download Staff-Panel-Minecraft-1.21.11.
11. Extract the downloaded artifact ZIP. Put the .jar inside your Minecraft .minecraft/mods folder.
12. Make sure Fabric Loader and Fabric API for Minecraft 1.21.11 are installed. Launch Minecraft.
13. Press K, or type /staffpanel in chat.

Do not put this mod inside ChatWatch. It is a separate mod and has its own config file: .minecraft/config/staff-panel.json.

If the Actions build fails, open the run, copy the first red error section, and share it before changing code.
